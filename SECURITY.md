# Security Policy

The latest published release receives security fixes. Update before reporting.

Report vulnerabilities privately at
https://github.com/nirupampal/india-invoice-utils/security/advisories/new.
Include affected versions, a minimal reproduction, expected and actual behavior,
and impact. Do not include customer data or secrets. Please allow investigation
and a coordinated fix before public disclosure.

Maintainers must enable GitHub private vulnerability reporting before publishing.
The maintainer aims to acknowledge reports within seven days; this is not a
guaranteed response SLA.

Validation is offline and syntactic. A valid checksum does not prove a GSTIN is
registered or active. This package does not establish ownership of an identifier,
determine legally applicable taxes, or replace server-side business validation.
